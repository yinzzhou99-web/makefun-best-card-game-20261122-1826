Ember Duel — an original turn-based card battler. You are the Ember Knight (30 life) against the Ash Baron (30 life): gain mana each turn, play creatures with Guard and Swift, hurl Fireballs, and reduce the Baron to zero life to win.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Mouse to play, keys 1–7 pick a hand card, Space ends your turn.
